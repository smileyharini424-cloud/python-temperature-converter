# Temperature Converter

## Explanation

This program converts temperatures between Celsius, Fahrenheit, and Kelvin.

## Problem Statement

Write a Python program that allows the user to convert a temperature from one unit to another.

## Features

* Celsius to Fahrenheit
* Fahrenheit to Celsius
* Celsius to Kelvin
* Kelvin to Celsius
* User-friendly menu

## How It Works

The program displays conversion choices and applies the appropriate temperature formula based on the selected option.

## Technologies Used

* Python 3

## Data Structure Used

* Floating-point variables

## Methods Used

* `input()`
* `float()`
* Conditional statements

## Program Flow

1. Display conversion menu
2. Read the user's choice
3. Read temperature
4. Apply conversion formula
5. Display converted temperature

## Sample Input

```text
1
25
```

## Sample Output

```text
Temperature in Fahrenheit: 77.0
```
